## 2026-07-27 — ТЗ-101: Матрица судьбы, базовая версия (8 точек + толкование)

### Шаг 0 — сверка формулы ДО написания кода

Формула из ТЗ **не совпала** с независимыми источниками — нашлась одна
конкретная ошибка, исправлена до реализации.

**Что оказалось неверным:** `C = сумма всех цифр полной даты рождения`.
Правильно: `C = сумма цифр ТОЛЬКО года` (`1990 → 1+9+9+0 = 19`).
Остальные пункты формулы (A, B, D, E и весь родовой квадрат F/G/H/I,
центр рода) подтвердились без изменений.

Ошибка неочевидная: «сумма цифр всей даты» и «A+B+C» дают одинаковый
результат по модулю 9, поэтому на многих датах они случайно совпадают
(на обоих опубликованных примерах ниже — совпали). Расходятся они
только когда результат попадает в диапазон 10–22: для 15.05.1990
правильный ответ 12, ошибочный — 3. Именно такую дату и брал для
проверки.

**Чем сверялся (4 независимых источника):**
1. Статья lady.mail.ru — разобранный пример Коко Шанель 19.08.1883
   (`19+8+20=47 → 11`, центр 13). Совпало.
2. Статья numefy.ru — разобранный пример 13.08.1991
   (`13+8+20=41 → 5`, центр 10 «Колесо Фортуны»). Совпало.
3. Исходники `github.com/3gr1v750v/fate_matrix-web` (Python/Flask) —
   совпадение буквально построчное по всем 9 точкам, включая
   адъяцентность родового квадрата.
4. Исходники `github.com/sanzol-tech/destiny-matrix` (JS) — совпало по
   A, B, C, всем четырём точкам родового квадрата и обоим центрам.
   Расхождение только по нижней точке D: там она считается как сумма
   цифр всей даты через конкатенацию строк (`dd+mm+yyyy`) — то есть
   ровно та ошибка, что была в ТЗ. На обоих опубликованных примерах
   выше она совпадает случайно, поэтому её и легко унаследовать.

| 29.08.1975 | 11,8,22,5,10,19,3,9,16 | совпало |
| 03.12.1987 | 3,12,7,22,8,15,19,11,7 | совпало |
| 01.01.2000 | 1,1,2,4,8,2,3,6,5 | совпало |

Даты подобраны под пограничные случаи: день > 22 (29 → 11, то есть
сумма цифр, а НЕ вычитание 22 — второе правило тоже гуляет по
интернету, но ни один из проверенных источников его не использует),
точка ровно 22 (не редуцируется дальше), и дата-расходитель 15.05.1990.
